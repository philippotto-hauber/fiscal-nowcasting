# fiscal-nowcasting

German fiscal nowcasting: MATLAB mixed-frequency dynamic factor model
(`src/*.m`, driven by `main.m`) fed by a Python data-building pipeline
(`src/*.py`).

state. At the start of a session, check it for context. When you wrap up a
meaningful chunk of work, add an entry (or update the "In progress" section)
so the next session can pick up where this one left off.
